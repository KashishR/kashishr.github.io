Mr. Byte

A neon arcade game that teaches players how encrypted data travels safely across the OSI network

TGC Solutions 2020 UX Design Game Design
Year 2020
Role UX/Game Designer
Ownership End-to-end game experience & learning mechanics

(01) — Context

Context

Mr. Byte is a neon arcade game built to teach players the concept of encrypted data transfer over the OSI network — and the potential security breaches at every layer of the model, along with the protective measures against them.

Terminal

Learn the concept of encrypted data transfer over the OSI network.

Enabling

Learning about the potential security breaches at every layer of the OSI model and protective measures against them.

Game Story: A Mission

Cyborgs have taken over the human race! But Mr. Agent has a way to save the humans. He has some important information that must reach his team on Raquet Island, which will help destroy the cyborgs. Mr. Byte has been chosen for this mission — he has to carry the information from headquarters to Raquet Island, while cyborgs try to attack him and he must protect the information from all possible attacks.

(02) — Approach

Approach

To make the security concepts stick, I translated each one into a game mechanic: a scoring system tied to security strength, a set of power tools for defense, ability badges to reward mastery, and a cast of cyborg antagonists representing different kinds of attacks.

Scoring Parameters

Security Strength

Keeps on increasing as the player successfully moves forward in the game.

Password Strength

Effective use of the password shield will increase password strength, which is important for high security strength.

Killed Cyborgs

Number of cyborgs that get killed. The security strength increases on killing the cyborgs.

Gameplay Power Tools

Password Shield

Use this tool to protect Mr. Byte from laser beams.

Laser Gun

Use this tool to shoot cyborgs to reduce their strength and speed.

Contact Headquarters

You can use this option only once per level, to get help from the headquarters.

Ability Badges

Laser Killer

Awarded when you kill more than 70% of the cyborgs to earn this badge.

Defence Master

Awarded when you dodge all laser beams to earn this badge.

Highly Secure

Awarded when you have a high security strength to get this badge.

Antagonists: Cyborgs

Bot Borg

These borgs attack and try to destroy Mr. Byte.

Laser Borg

They shoot high-intensity lasers to corrupt the information.

Ani Borg

They are the strongest and will try to eat Mr. Byte.

(03) — Outcome

Outcome

The result is a full arcade experience that wraps the lesson in gameplay: vehicle-selection analogies for choosing a path, a leaderboard for healthy competition, an encryption shield mechanic to block cyborg attacks, and trivia checkpoints that confirm what players learned.

Analogies using game elements

Leaderboard to induce healthy competition

Using encryption to shield cyborg attacks

Trivia to ensure learning
